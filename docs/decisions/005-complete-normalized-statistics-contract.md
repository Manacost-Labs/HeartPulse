# ADR-005: Полная статистика через версионированную allowlist-модель

## Статус

Принято.

## Дата

2026-07-30.

## Контекст

Public API нужен приложению, аналогичному Hearthstone Deck Tracker. Клиенту
необходимы все доступные показатели Constructed, Арены и Полей сражений,
включая вложенные срезы и историю. Источники имеют разные имена полей, единицы,
частоту обновления и могут без предупреждения добавлять служебные ключи.

Слепая передача provider JSON дала бы формально «все поля», но сделала бы
контракт нестабильным и могла раскрыть URL, состояние парсеров, внутренние id
или будущие секретные поля.

## Решение

Считать API полным, если каждое известное статистическое значение источника
представлено в нормализованной allowlist-схеме. Новые provider-поля не
пробрасываются автоматически. Для каждого нового показателя обязательны:

- стабильное публичное имя и единица измерения;
- явная nullable-семантика;
- контрактный тест;
- OpenAPI 3.1;
- обновление матрицы покрытия.

Текущие снимки, история и вложенные статистические структуры публикуются
полностью, если они существуют в серверном хранилище. Отсутствующая история не
синтезируется.

## Рассмотренные альтернативы

### Передавать raw JSON провайдера

Плюс: новое поле появляется без разработки. Минусы: отсутствие стабильного
контракта, разные единицы и имена, риск утечки инфраструктурных данных.
Отклонено.

### Публиковать только основные метрики

Плюс: небольшой контракт. Минус: недостаточно для полноценного трекера и
аналитики. Отклонено.

### GraphQL поверх raw-источников

Плюс: гибкий выбор полей. Минусы: схема всё равно требует нормализации, а
переход добавляет второй API-стек без устранения рисков источника. Отложено.

## Последствия

- Клиент получает все доступные статистические значения в одном стабильном
  формате.
- Отсутствующий показатель однозначно выражается `null`, а не нулём.
- Добавление нового показателя требует изменения версии контракта и тестов.
- Изображения, карточные данные и авторизация остаются отдельными модулями API.
- Полнота проверяется матрицей
  `docs/specs/public-api-statistics-coverage.md`, а не количеством raw-ключей.
