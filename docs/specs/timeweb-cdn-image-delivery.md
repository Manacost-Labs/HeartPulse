# Спецификация: доставка изображений через Timeweb CDN

## Цель

Ускорить загрузку изображений карт для пользователей в России и Европе, не делая доступность сайта зависимой от одного CDN-адреса. Пользовательские страницы и API продолжают работать через `arena.hs-manacost.ru`, а совместимые публичные изображения могут загружаться через `cdn.arena.hs-manacost.ru`.

## Технологии

- React 19 и TypeScript 5.8;
- Vite 6;
- Express 4 как origin для `/api/card-image/**`;
- Timeweb CDN как распределённый кэш;
- Cloudflare Authoritative DNS для зоны `hs-manacost.ru`.

## Команды

- Установка: `npm ci`;
- Проверка типов: `npm run lint`;
- Тесты изображений карт: `npm run test:card-image-delivery-config && npm run test:constructed-card-media && npm run test:card-image-routes`;
- Сборка: `npm run build`;
- Проверка безопасности изменённого TypeScript: `npm run security:semgrep`;
- Проверка секретов перед публикацией: `npm run security:gitleaks`.

## Структура

- `shared/` — чистая политика преобразования URL, общая для браузерного и серверного кода;
- `src/config/` — чтение клиентской конфигурации доставки;
- `src/features/constructedCardMedia.ts` — формирование URL изображений обычных, связанных и генерируемых карт;
- `tests/` — unit- и contract-тесты URL-политики;
- `docs/runbooks/` — проверка CDN, переключение и откат.

## Стиль кода

Политика URL остаётся чистой функцией: входной путь и явная конфигурация дают предсказуемый результат без сетевых запросов и скрытого состояния.

```ts
const result = resolveCardImageDeliveryUrl('/api/card-image/126055/full.webp?v=release', {
  enabled: true,
  origin: 'https://cdn.arena.hs-manacost.ru',
});
```

## Стратегия тестирования

1. Unit-тест сначала фиксирует разрешённые пути, выключенный флаг и недопустимый origin.
2. Существующие тесты изображений доказывают отсутствие регрессий в URL и версиях кэша.
3. Сборка доказывает совместимость клиентского и серверного TypeScript.
4. После активации выполняется реальная браузерная проверка карточного каталога, detail page, lightbox и скачивания.
5. Синхронизированная карта должна сразу возвращать `LOCAL`; только отсутствующий локальный объект может пройти через `MISS` и последующий `HIT`.

## Границы

### Всегда

- использовать только HTTPS;
- переписывать только явно разрешённые публичные GET/HEAD-ресурсы;
- сохранять path, query string и версионирование кэша;
- иметь быстрый способ отключить CDN без изменения данных;
- измерять скорость до и после включения.

### Сначала согласовать

- перенос API JSON, авторизации или персональных данных на CDN;
- изменение CORS для произвольных origin;
- включение оптимизации изображений CDN, меняющей качество оригинала.

### Никогда

- не отправлять через CDN cookies, API-ключи или приватные ответы;
- не хранить токены Cloudflare и Timeweb в репозитории;
- не направлять origin-домен на собственный CDN-домен, создавая петлю.

## Критерии готовности

- `cdn.arena.hs-manacost.ru` направляется GeoDNS на региональные edge и имеет валидный TLS;
- региональный edge обслуживает синхронизированные карты local-first;
- технический домен Timeweb остаётся резервным upstream для локальных промахов;
- изображения `/api/card-image/**` успешно отдаются через CDN;
- повторный запрос получает CDN cache hit;
- приложение использует единый URL-провайдер с выключенным по умолчанию переключателем;
- при выключенном CDN поведение полностью совпадает с текущим production;
- тесты, typecheck, security-проверки и browser review проходят.

## Состояние production

Собственный домен, TLS, региональный GeoDNS, local-first зеркало, Timeweb upstream, origin-fallback и runtime-переключатель включены. Серверный API-токен хранится вне репозитория с правами `0600`; токены из чатов не считаются долговременным секретом и подлежат ротации.
