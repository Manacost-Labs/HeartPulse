# Spec: статистика существа Полей сражений

## Objective

На странице существа активного пула (`/library/minions/<slug>-<dbfId>/`)
подписчик видит статистику HSReplay из hs-data-api: шапку с KPI, силу по
ходам, покупки по ходам и позиции на столе. Гость видит прежнее превью с
paywall; логика доступа не меняется.

## Data contract

- Источник: `GET {HS_DATA_API_BASE_URL}/v1/battlegrounds/minions/{dbfId}/stats`
  (срез по умолчанию: MMR топ-50%, последние 7 дней), для позиций одного
  состава — `?composition=<id>`.
- Сайт: `GET /api/bg/library/minions/:dbfId/stats[?composition=N]` за
  `requireBattlegroundsAccess`, ответ `private, no-store`.
  - `200` — `BattlegroundMinionStats` из
    `server/modules/battlegroundLibrary/minionStatsContract.ts` (зеркало для
    браузера — `src/modules/battlegrounds/model/minionStats.ts`);
  - `404` — у существа нет среза или нет ни одной игры (обычной и золотой);
  - `400` — `dbfId` или `composition` не целые положительные числа;
  - `502` — hs-data-api недоступен или нарушил контракт.
- `parseBattlegroundMinionStats` проверяет форму и диапазоны, оставляет только
  то, что рисует страница, и переводит картинки в `/api/public-resource/db/…`.
  `null` всегда значит «ниже порога выборки» (30 игр, боёв или предложений;
  200 досок для влияния позиции), а не ноль. Английские формулы
  `methodology` на страницу не попадают: подсказка пересказывает их по-русски.
- Кэш Express (`server/modules/battlegroundLibrary/minionStats.ts`): час для
  ответа с данными, 10 минут для `404`, до 600 ключей, общий запрос для
  одновременных чтений; ошибки не кэшируются.

## Presentation

- Шапка `BattlegroundMinionHeader`: арт карты (оптимизатор, 512 px; горизонтальный
  арт API — полоса 320×64 и для фона не годится), рендер карты и переключатель
  «Обычная / Золотая», тир, тип, механики, текст карты, KPI выбранной версии:
  разница среднего места с существом и без (с ним минус без: меньше — лучше,
  первым, зелёная или красная), винрейт боёв, популярность, влияние (знак
  HSReplay: больше — лучше), игры. Знаки двух метрик противоположны, поэтому
  обе подписаны словами одинаково: «на 0,20 места лучше / хуже» или «как без
  него». Строка источника и подсказка методики.
- «Сила по ходам»: `LineChart` винрейта боёв (полоса — 95% интервал Уилсона по
  боям), влияния и медианной атаки. Медиана рисуется, только если меняется по
  ходам с выборкой. Раскладка зависит от ширины секции (container query
  `minion-section`): узкая — один столбец, от 40rem — два, нечётный последний
  график на всю строку, от 60rem — три графика в ряд.
- «Когда покупают»: `Heatmap` (VaryloUI) — 1–3-я копия и раскопка по ходам.
- «Позиция на столе»: 7 мест с теплом по доле досок и влиянием места;
  обычная доска / с провокацией и выбор состава (повторный запрос позиций).
  Уже 30rem места переносятся рядами по четыре: семь в ряд оставляли телефону
  около 45px на место, и проценты наезжали друг на друга.
- Загрузка: тот же каркас шапки (`BattlegroundMinionHeader loading` в
  `BgLibraryDetailSkeleton`) с теми же высотами плиток KPI и строки источника,
  поэтому шапка не сдвигается, когда приходят данные
  (`tests/skeleton-geometry-browser.test.mjs`).
- «Используется в стратегиях» (существа и заклинания активного пула): строки-
  ссылки «источник · тир», имя сборки, одна строка описания без повтора имени
  (сборки HSReplay и Firestone есть только на английском), до пяти ключевых
  существ мини-плитками — сначала текущее, затем ядро; сортировка по тиру,
  первые пять, остальные за «Показать все» (`bgLibraryStrategyRows.ts`).
- Нет игр — строка вместо KPI и без разделов; недоступный источник — строка
  «Статистика HSReplay сейчас недоступна».
