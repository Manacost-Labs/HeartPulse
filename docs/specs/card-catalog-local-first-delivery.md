# Спецификация: local-first доставка изображений каталога карт

## Цель

Убрать задержку холодного CDN-кэша при открытии `/standard/cards/` и при смене фильтров. Уже синхронизированное изображение должно читаться с локального диска выбранного регионального edge. Timeweb CDN и основной origin используются только когда локальной копии нет.

## Подтверждённая причина

- каждый edge хранит `/srv/arena/card-images/current`; на европейском узле доступно 15 188 файлов;
- application-host `arena.hs-manacost.ru` читает эти файлы local-first;
- CDN-host `cdn.arena.hs-manacost.ru` до исправления пропускает локальное зеркало и всегда обращается к Timeweb;
- холодный запрос измерен примерно в `0,67 с`, тогда как локальный same-origin ответ — примерно `0,10 с`;
- повторный edge-cache hit быстрее, но не помогает новым версиям изображений сразу после патча.

## Технологии и структура

- Nginx на европейском, московском и новосибирском edge;
- `deploy/nginx/arena-card-local-maps.conf` — безопасное сопоставление API URL с локальным именем файла;
- `deploy/nginx/arena-cdn-card-image-cache.conf` — новый CDN local-first маршрут;
- `scripts/create-release.mjs` — включает конфигурацию в неизменяемый release contract;
- `tests/nginx-html-routing.test.mjs` и `tests/create-release.test.mjs` — контракт маршрута и артефакта.

## Политика маршрута

1. Разрешать только `GET` и `HEAD` для `/api/card-image/**`.
2. Искать Blizzard-вариант локально.
3. Затем искать fallback-вариант и локальный placeholder.
4. Только после локальных промахов обращаться к Timeweb CDN.
5. При `404` или ошибках Timeweb `500`, `502`, `503`, `504` использовать основной origin.
6. Не передавать upstream cookie, authorization и тело запроса.
7. Сохранять query string в cache key удалённого fallback, чтобы версии изображений не смешивались.

## Стратегия тестирования

1. Сначала добавить падающий contract-тест local-first маршрута.
2. Добавить Nginx snippet и включить его в release manifest.
3. Выполнить `node tests/nginx-html-routing.test.mjs` и `node tests/create-release.test.mjs`.
4. На каждом edge выполнить `nginx -t` до reload.
5. Проверить известную карту: ответ CDN должен иметь `X-Proxy-Cache: LOCAL`, а время ответа не должно зависеть от Timeweb.
6. Проверить отсутствующий локальный файл: запрос должен безопасно пройти резервную цепочку, не раскрывая приватные заголовки.
7. Проверить каталог в реальном браузере на desktop и mobile без визуальных регрессий и ошибок изображений.

## Границы

### Всегда

- сохранять локальное зеркало атомарным и неизменяемым для активной версии;
- проверять все три региона;
- документировать измерения до и после;
- иметь откат через возврат предыдущего snippet и `nginx reload`.

### Никогда

- не кэшировать авторизацию или приватный API на CDN-host;
- не разрешать произвольные пути к файловой системе;
- не возвращать `immutable` для отсутствующего объекта;
- не отключать региональные прокси ради одного локального измерения.

## Критерии готовности

- CDN-запрос существующей карты во всех регионах возвращает `200` и `X-Proxy-Cache: LOCAL`;
- новые карточки используют локальный sync сразу после публикации;
- Timeweb остаётся резервом, а не обязательным первым hop;
- contract-тесты, сборка, security-проверки и production smoke проходят;
- runbook и changelog описывают причину, проверку и откат.
