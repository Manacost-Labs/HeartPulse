# Аберрации на Полях сражений

Тип HearthstoneJSON `ABERRATION` соответствует `creature_type.slug: aberration`
и русскому названию «Аберрация» в библиотечном API. Фильтры тир-листов и
конструкторов используют название «Аберрации». Неизвестные типы и существа
без типа сохраняют прежнее поведение.

Иконка фильтра — локальная копия предоставленного изображения
`https://art.hearthstonejson.com/v1/256x/TB_BaconShop_HP_041l.webp`.
Она используется в библиотеке, тир-листах, деталях карт и конструкторах.

Заклинания и аксессуары остаются в собственных разделах. Их наличие проверяется
по полному активному пулу API, включая все страницы аксессуаров. Связь с
аберрациями сама по себе не превращает заклинание или аксессуар в существо.

## Реализация и проверка

- Источник: импортер `panel/scripts/scan_cards.php` и справочник
  `panel/api/index.php` в репозитории `hs-data-api`.
- Клиент: существующие справочники в `src/features/BgLibrary.tsx`,
  `src/features/Battlegrounds.tsx` и `public/bg-legacy/*builder*.js`.
- Общий справочник иконок библиотеки и деталей принадлежит
  `src/modules/battlegrounds/model/minionTypeIcons.ts` и доступен через
  публичный контракт модуля; это сохраняет ограничение размера legacy route.
- Сохраняются существующие форматирование и архитектурные границы;
  новые зависимости, маршруты и схемы БД не нужны.
- Проверки: `npm run test:battleground-accessories`, `npx tsc --noEmit`,
  `npm run security:semgrep`, `npm run test:storybook`,
  `npm run build-storybook`, `npm run build` и проверка фильтров в браузере
  на desktop/mobile. Регрессия импортера выполняется через
  `php panel/tests/battleground_creature_types_test.php`.
- Воспроизводимый пример: `BG36_110` («Счастье») должен иметь тип
  `aberration`, а не `null`; базовая и золотая версии используют одинаковое
  преобразование типа.

Порядок обновления существующих записей описан в
[`battlegrounds-patch-refresh.md`](../runbooks/battlegrounds-patch-refresh.md).
