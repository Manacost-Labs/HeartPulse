# Периоды меты `/standard/meta/`

Источник — матрица HSGuru в hs-data-api (`/v1/hsguru/meta`, `hsguru_meta_matrix`).
Список периодов повторяет меню HSGuru (проверено 2026-10-20) и приходит в
ответе как `availablePeriods`; `currentPeriod` — окно текущего дополнения,
`currentPatchPeriod` — текущий патч.

| Идентификатор | Подпись | Примечание |
| --- | --- | --- |
| `black_empire_ban` | Баны | После обновления с запретами, первым в списке |
| `black_empire` | Тёмная империя | «Власть Темной империи», по умолчанию |
| `patch_<версия>` | Патч 36.6.3 | Текущий патч, версия приходит из источника |
| `past_3_hours` | 3 часа | Узкие ранги могут быть пустыми |
| `past_6_hours` | 6 часов | Узкие ранги могут быть пустыми |
| `past_day` | Сутки | Период Express по умолчанию без параметра |
| `past_3_days` | 3 дня | |
| `past_week` | Неделя | |
| `past_2_weeks` | 2 недели | |
| `past_30_days` | 30 дней | |

Порядок в селекторе: окно банов (`*_ban`), `currentPeriod`, `currentPatchPeriod`,
затем скользящие окна от коротких к длинным.

## Очерёдность хода

Фильтр «Очерёдность хода» передаётся как `coin` и повторяет фильтр HSGuru
`player_has_coin`:

| `coin` | Подпись | HSGuru |
| --- | --- | --- |
| `any_player` | Любая | без фильтра, по умолчанию |
| `going_first` | Ходит первым | `player_has_coin=no` |
| `on_coin` | С монеткой | `player_has_coin=yes` |

hs-data-api собирает оба варианта для всех рангов страницы и всех периодов.
Узкие ранги в коротких окнах могут быть пустыми.

## Совместимость старых ссылок

- `period=violet_hold` и `period=most_wanted` (снятые окна прошлых дополнений)
  открывают `black_empire`: `/api/standard-meta` подменяет их до запроса к
  источнику.
- Патч, который источник больше не собирает (HTTP 422 от hs-data-api),
  открывает текущий патч из среза `past_day`.
- Неизвестный период — HTTP 400 до запроса к источнику.

Снятые идентификаторы остаются допустимыми в контракте ответа
(`shared/standardMetaPeriods.ts`), чтобы последний сохранённый срез читался,
пока источник не опубликует новую матрицу.

Данные матрицы обновляются раз в 12 часов, поэтому окна «3 часа» и «6 часов»
показывают последние 3/6 часов на момент обновления (`updatedAt`).

Изменение к предыдущему окну и тренд по окнам: `docs/specs/standard-meta-trends.md`.
