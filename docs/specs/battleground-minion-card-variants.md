# Spec: варианты существ Полей сражений

## Objective

На странице существа Полей сражений показать переключатель «Обычная / Золотая», если в каталоге существует золотая версия карты. Переключение должно менять изображение, текст эффекта, атаку, здоровье и ссылку на wiki на данные выбранной записи.

## Tech stack and commands

- React 19, TypeScript 5.8, Vite 6, Storybook 10.
- Test: `tsx tests/battleground-card-variants.test.ts`
- Type check: `npm run lint`
- Storybook: `npm run test:storybook && npm run build-storybook`
- Build: `npm run build`

## Project structure

- `src/features/BgLibrary.tsx` — загрузка и страница карточки.
- `src/features/BattlegroundCardVariantToggle.tsx` — доступный переключатель.
- `src/features/battlegroundCardVariants.ts` — связь обычной и золотой записей.
- `tests/battleground-card-variants.test.ts` — контракт выбора пары.

## Code style and accessibility

- Использовать существующие цвета, типографику и скругления библиотеки.
- Использовать нативные `<button>` с `aria-pressed` и общей доступной подписью.
- Не вычислять золотые характеристики: отображать только значения записи API.
- Не показывать переключатель, если точная золотая запись или её изображение отсутствуют.

## Testing strategy

- Unit: поиск золотой записи по базовому `card_id`, включая суффиксы `_G` и `_Gt`.
- Storybook: обычное и золотое состояния, клик по кнопке и проверка `aria-pressed`.
- Browser: архивная страница DBF 106487 на desktop и mobile, консоль и сеть без новых ошибок.

## Boundaries

- Always: запрашивать только пару текущей карты через `q`, сохранять обычный вариант по умолчанию.
- Ask first: изменение схемы каталога или миграция данных.
- Never: удваивать характеристики или текст эвристикой, загружать весь архив ради одной пары.

## Success criteria

- На DBF 106487 видны две кнопки; золотая версия показывает 4/4 и эффект +2/+2, обычная — 2/2 и +1/+1.
- Кнопки работают мышью, клавиатурой и сообщают выбранное состояние assistive technology.
- Карты без надёжной золотой пары сохраняют прежний вид без пустого переключателя.
