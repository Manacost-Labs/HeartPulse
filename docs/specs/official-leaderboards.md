# Таблицы лидеров

Страница `/leaderboards/` (меню «Разное» → «Таблицы лидеров») показывает
официальные таблицы лидеров Blizzard: Стандарт, Вольный, Поля сражений
(соло и дуо), Арену, Подземную арену и Твист в регионах Европа, Америка и
Азия — места, рейтинг, пороги топа и историю игрока по дням.

## Поток данных

1. hs-data-api собирает таблицы с публичного API Blizzard
   (`hearthstone.blizzard.com/en-us/api/community/leaderboardsData`): текущие
   сезоны целиком каждые 6 часов, прошлые сезоны — один раз фоновой
   дочиткой. Каждая таблица хранит не больше одного снимка в UTC-сутки.
   Таблицы больше 50 000 мест (старые сезоны Полей сражений) хранятся
   первыми 50 000 местами и помечены `truncated`. Подробно —
   `docs/BLIZZARD_LEADERBOARDS.md` репозитория hs-data-api.
2. Express (`server/modules/leaderboards`) читает
   `GET /v1/leaderboards*` (`HS_DATA_API_BASE_URL`, по умолчанию
   `https://api.kolodahearthstone.com`), проверяет ответ и приводит его к
   модели страницы (`contract.ts`). Ответы кешируются по URL на 2 минуты
   (до 500 записей), одновременные одинаковые запросы читают hs-data-api
   один раз, неудача не кешируется.
3. Публичные анонимные маршруты, все с
   `Cache-Control: public, max-age=60, stale-while-revalidate=300`:

   | Маршрут | Параметры | Ответ |
   | --- | --- | --- |
   | `GET /api/leaderboards/seasons` | — | Режимы, регионы и сезоны с сохранённой таблицей, новые первыми |
   | `GET /api/leaderboards/table` | `mode`, `region`, `season`, `page` (1–1000), `q` (≤ 32 символов) | Страница таблицы по 50 строк: место, ник, рейтинг, место в предыдущем снимке |
   | `GET /api/leaderboards/stats` | `mode`, `region`, `season` | Игроков в таблице, рейтинг 1-го места, пороги топ-100/1000/5000, распределение рейтинга, ряды по дням |
   | `GET /api/leaderboards/player` | `region`, `name` | Все сохранённые сезоны игрока: лучшее и последнее место, ряд по дням |
   | `GET /api/leaderboards/players` | `q` (≥ 2 символов), `region` | До 8 игроков по началу ника и их места в текущих сезонах |

   Неверные параметры — `400`; несобранная таблица или неизвестный игрок —
   `404` с русским `error`; ошибка hs-data-api — `502` и `no-store`.
4. Next (`apps/public-web/app/leaderboards/page.tsx`) читает выбор из
   строки запроса и за общий бюджет первого кадра параллельно загружает
   каталог сезонов, страницу таблицы и сводку. Что не успело, браузер
   загружает сам и до ответа показывает скелетон.

## Страница

- Выбор режима, региона, сезона, номер страницы, поиск и открытый игрок
  живут в строке адреса (`mode`, `region`, `season`, `page`, `q`, `player`):
  ссылкой можно поделиться. Значения по умолчанию — Стандарт, Европа,
  последний сохранённый сезон.
- «Пороги и статистика»: игроков в таблице и изменение за день; у режимов
  с рейтингом — рейтинг 1-го места и пороги топ-100/1000/5000; графики
  «Игроков в таблице по дням», «Порог топ-1000 (или 100) по дням» и
  «Распределение рейтинга». Режимы без рейтинга (Стандарт, Вольный, Твист)
  показывают только места: Blizzard публикует лишь Легенду без MMR.
- Таблица: место, ник, рейтинг (MMR Полей сражений, среднее число побед
  Арены, очки Подземной арены) и «За сутки» — изменение места к
  предыдущему снимку («Новый» — игрока там не было). Колонка появляется,
  когда у сезона есть хотя бы два снимка.
- Нажатие на ник открывает карточку игрока: места в текущих сезонах, график
  места по дням выбранного сезона (первое место сверху) и таблица всех его
  сезонов. Blizzard показывает ник без номера BattleTag, поэтому одноимённые
  аккаунты региона объединены, и карточка об этом предупреждает.
- Пока грузится другая страница или таблица, прежняя остаётся на месте
  приглушённой (`aria-busy`); скелетон — только когда данных ещё нет.
- Время снимка — по Москве, собранное вручную, чтобы HTML сервера и
  гидратация совпадали.
