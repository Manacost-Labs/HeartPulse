# Изображения героев Полей сражений

## Правило выбора портрета

Список и таблица героев должны показывать овальный портрет героя, а не карту
силы героя. Источники выбираются в следующем порядке:

1. выделенный портрет из статистического API;
2. выделенный портрет из библиотеки `db.kolodahs.ru`;
3. локальная legacy-карта изображений;
4. общий `/api/card-image/{card_id}/full.webp` как последний резерв;
5. локальная заглушка, если идентификатор карты отсутствует.

Общий карточный кеш нельзя ставить первым. Blizzard отдает для части старых
`TB_BaconShop_HERO_*` изображение в прямоугольной рамке карты с нулевой маной,
а не овальный портрет героя. Новые `BG36_HERO_*` могут выглядеть корректно в
том же кеше, поэтому проверка только новых ID не обнаруживает регрессию.

Известные внешние URL преобразуются `publicResourceUrl` в same-origin
`/api/public-resource/*` на границе рендера. Так портреты кешируются Arena и не
зависят от прямого доступа посетителя к Hearthstone Wiki.

## Проверка после обновления данных

Для каждого текущего героя проверить:

- `image` заполнено;
- URL не указывает на силу героя (`_HP_` или суффикс `p`);
- изображение через `/api/public-resource/*` отвечает `200`;
- тело ответа непустое и декодируется как изображение;
- в браузере отсутствуют ошибки загрузки изображений.

Минимальный регрессионный набор должен включать новый
`BG36_HERO_105` и старый `TB_BaconShop_HERO_17`. После изменения источников
также проверяются карточный и табличный виды на desktop и mobile.
