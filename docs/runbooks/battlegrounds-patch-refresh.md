# Обновление данных после патча Полей сражений

## Источники и порядок проверки

1. Сверить состав патча с официальными примечаниями Blizzard.
2. Запустить `kolodahs-sync@cards.service` для существ и заклинаний.
3. Запустить `kolodahs-sync@libraries.service` для дополнительных библиотек.
4. Запустить `kolodahs-sync@heroes-refresh.service`, если добавлены герои.
5. Проверить публичные API `db.kolodahs.ru` и прокси `arena.hs-manacost.ru`.
6. Очистить прикладной кеш перезапуском `hs-arena.service`, только если публичный
   ответ продолжает содержать старую версию после успешного импорта.

## Темные дары сезона 14

Blizzard не предоставляет для Темных даров отдельный `bgCardType`. Импорт
обнаруживает их в HearthstoneJSON по стабильному префиксу
`BG36_MidGameEffect_000t` и типу `SPELL`. Ожидаемое число карточек для патча
36.2 — 43. Они доступны через `/api/v1/dark-gifts` и проксируются приложением
через `/api/bg/library/extra/dark_gift`.

## Золотые версии новых существ

`sync_battlegrounds_images.py` всегда предпочитает локализованный `imageGold`
из Blizzard API. После выхода патча карточки HearthstoneJSON могут появиться
раньше, чем Blizzard начнет возвращать их изображения. Для существ, у которых
золотого изображения еще никогда не было, синхронизатор временно загружает
полный golden-рендер HearthPwn в `/uploads/golden/{card_id}.png` и публикует
локальный URL только после проверки PNG и атомарной записи файла.

Fallback не перезаписывает уже существующие локальные изображения. Когда
Blizzard начинает возвращать `imageGold`, изменившийся URL источника
автоматически заменяет временный рендер локализованной версией Blizzard.

## Временные исправления текста Constructed

Свежий балансный патч иногда появляется в примечаниях раньше, чем в API
Blizzard. `sync_constructed_cards.py` допускает узкие текстовые исправления,
которые применяются только при наличии маркера старого текста. После обновления
официального API такое исправление автоматически перестает влиять на запись.

## Контрольный список

- количество новых карт совпадает с примечаниями к патчу;
- русские и английские названия и тексты заполнены;
- изображения отвечают `200`;
- у каждого активного нового существа заполнено `images.golden`, а файл имеет
  ожидаемую геометрию `512x776`;
- новые герои содержат силу героя;
- публичный ответ Arena совпадает с ответом базы;
- `/health/data` не показывает новый источник как устаревший.
