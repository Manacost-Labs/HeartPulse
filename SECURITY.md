# Политика безопасности

## Сообщение об уязвимости

Не публикуйте уязвимости, токены, персональные данные или инструкции по
эксплуатации в обычных GitHub Issues.

Используйте приватный отчёт в разделе **Security → Advisories → Report a
vulnerability** репозитория. Укажите затронутый маршрут или компонент,
минимальные шаги воспроизведения, ожидаемое влияние и безопасный способ
проверки исправления.

## Поддерживаемая версия

Исправления безопасности выпускаются для текущей версии ветки `main`, которая
развёрнута на `https://hearthpulse.net`. Старые production-снимки
поддерживаются только как краткосрочные rollback-артефакты.

## Координация

Команда подтвердит получение отчёта после первичной проверки. Срок исправления
зависит от риска и сложности безопасного развёртывания. Не раскрывайте детали
публично до выхода исправления и подтверждения production.
