Браузерные тесты теперь запускают Chrome через общий `launchBrowser` (таймаут запуска 60 секунд и один повтор при таймауте DevTools endpoint), поэтому медленный старт Chrome на раннере GitHub больше не роняет CI и не уводит тест в перезапуск. Прямой `puppeteer.launch` в `tests/` запрещён правилом oxlint `no-restricted-imports`, которое входит в проверку «Typecheck, lint and static gates».
