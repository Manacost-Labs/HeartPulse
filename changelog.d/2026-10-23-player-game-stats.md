В личном кабинете появился раздел «Моя статистика», как «My Stats» в HSReplay: игры из приложения Hearthpulse по Полям сражений, Стандарту, Вольному и Арене. Для Полей сражений — лучший рейтинг, среднее место, распределение мест, график рейтинга с финальной доской каждой игры и таблица героев с боями по ходам; для Стандарта и Вольного — ранг по играм, колоды, классы, соперники и матчапы; для Арены — забеги, средние победы и классы. С подпиской на раздел показывается сравнение со всеми игроками. Для приложения добавлен приём игр `POST /api/v1/me/games` и проверка синхронизации `GET /api/v1/me/games` по токену входа HeartPulse.
