CI получил отчёты времени по каждому тестовому файлу и калибровку весов по успешным полным прогонам. Проверки распределены между четырьмя registry jobs, десятью браузерными jobs и четырьмя парами browser observatory; независимые длинные сценарии разделены с сохранением проверок и viewport, включая две группы мобильной геометрии всех семи маршрутов. Повторно используются готовые сборки, системный Chrome, nginx и OpenSSL; добавлены прогрев браузера, диагностика ресурсов, состояния процесса и ввода-вывода Chrome при прогреве пустой страницы. Для проверки задержек чтения Chrome добавлен ограниченный эксперимент предварительного чтения исполняемого файла перед браузерными шардами и observatory с сохранением обычного запуска при ошибке. Добавлен эксперимент передачи сборки единым сжатым архивом с отдельными замерами загрузки и распаковки и проверкой сохранности файлов. В browser QA паузы между шагами подсказок заменены ожиданием завершения анимаций и стабильной геометрии с сохранением проверок положения, фокуса и доступности. Авторитетная проверка типов Next, Storybook, визуальные ограничения и все обязательные проверки сохранены. Исправлены преждевременная готовность тестового backend, утечки серверов при ошибке подготовки и воспроизведённые гонки браузерных fixtures, включая истечение запроса leaderboards во время подготовки эталонных страниц без увеличения таймаутов и ослабления assertions; проверки библиотеки Battlegrounds ожидают загрузку документа, готовое состояние доступа, шрифты и анимации перед чтением paywall вместо ожидания сетевого затишья; HTML тестовой fixture отдаётся из памяти без чтения файла на каждый запрос; результаты и ограничения замеров записаны в runbook CI.

- Desktop-проверка геометрии семи маршрутов разделена на две независимые группы по существующей схеме mobile; все измерения, CLS, viewport и assertions сохранены.

- В ошибку браузерного теста закрытия lightbox добавлены ограниченные события CSS-перехода и изменения opacity для диагностики нестабильного сбоя без изменения проверок.

- Независимые проверки Arena paywall для гостя, сдвига layout и доступа администратора распределены по трём файлам; тела сценариев, оба CLS viewport, ожидания и assertions сохранены.

- Аудит canonical-ссылок разделён на гостевую и подписочную группы с сохранением серверных и гидратированных ссылок, проверок архива, hover-prefetch и перехода без перезагрузки документа.

- Оценки времени для 555 обязательных тестовых файлов перекалиброваны по медианам двух полных успешных запусков с одинаковым кодом; покрытие и число workers сохранены.

В браузерной проверке identity continuation первый кадр формы фиксируется до запуска секундного ответа фикстуры: задержка тестового драйвера больше не подменяет ранний кадр уже загруженным названием сайта. Проверки текста, геометрии и viewport сохранены.

Проверка фокуса полей ждёт готовность стилей, шрифтов и обработчика переключения мышь/Tab вместо полной сетевой тишины. Все три маршрута, две ширины экрана и исходные проверки сохранены.

Добавлен экспериментальный CI-кеш установленного Chrome с точной привязкой к версии пакета и образу runner. При отсутствии подходящего кеша остаётся системный браузер; набор тестов и обязательные проверки сохранены.

Восстановленный Chrome использует исходный root-owned sandbox helper установленного пакета; при неподходящем helper сохраняется системный браузер. Это исправляет запуск sandboxed radar-теста без ослабления sandbox или assertions.

Лог выбора Chrome теперь указывает точную причину возврата к системному браузеру либо подтверждает выбор кеша; проверки sandbox и набор тестов сохранены.

Кешированный Chrome выбирается только для CI-запусков с уже заданным `--no-sandbox`; sandboxed-тесты и явно выбранные другие браузеры продолжают использовать исходный executable. Флаги запуска не меняются, источник браузера виден в логе.

Измерение fade в lightbox-тесте сохраняет реальные параметры перехода при готовности анимации, до возможного удаления элемента. Исходные проверки длительности, порядка удаления, кадров и reduced motion сохранены.

Registry jobs восстанавливают кеш npm-архивов даже при готовом `node_modules`, чтобы отдельная чистая production-установка использовала уже загруженные пакеты. `npm ci --omit=dev` и проверки runtime сохранены. Диагностика lightbox дополнена состоянием захваченной анимации без изменения assertions.

Гостевые проверки конструкторов БГ ждут готовый paywall, шрифты и завершение конечных анимаций вместо сетевой тишины. Все маршруты, ширины, проверки доступности и запрета защищённых запросов сохранены; сценарии подписчика не менялись.

Исправлено преждевременное закрытие lightbox героя на занятом renderer: резервный таймер ждёт уже запланированный переход прозрачности вместо удаления до его завершения. Добавлен тест задержанного fade; закрытие без анимации, при отмене перехода и reduced motion проверено.

Проверки фильтров фан-колод ждут готовые составы колод, шрифты и анимации вместо сетевой тишины. Проверки фильтров, перезагрузки, мобильной геометрии, доступности и скриншоты сохранены.

Веса обязательных тестов обновлены по двум полным успешным прогонам одинакового кода. Проверено однократное покрытие всех 555 файлов; число workers, quarantine и правила повторов сохранены. Новое распределение проверяется в GitHub CI.

Проверка устойчивости формы входа ждёт появления имени сайта и полного набора кадров вместо фиксированной паузы. Все 14 сочетаний сайта и ширины, задержка фикстуры и пороги CLS/сдвига формы сохранены; искусственный сдвиг по-прежнему обнаруживается.

Адаптивные скриншоты больше не ждут декодирования lazy-изображений целиком за пределами кадра. Частично видимые и обычные изображения по-прежнему ожидаются; все маршруты, размеры, скриншоты и проверки сохранены.

Измерение геометрии skeleton теперь запускает загрузку lazy-изображений внутри измеряемого контейнера, даже если они остаются за экраном после прокрутки. Ожидание load/error, окна наблюдения CLS, варианты текста и геометрические проверки сохранены.

Тестовый backend получает ограниченный 30-секундный бюджет запуска вместо 300 опросов. Готовность по-прежнему требует сообщения собственного процесса, успешного health endpoint и созданной БД; добавлены проверки задержанного старта, дедлайна и очистки ресурсов.
