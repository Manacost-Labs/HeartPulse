CI использует изолированные параллельные тестовые процессы, свежие веса и восемь независимых групп observatory на общей сборке. Длинные проверки skeleton, paywall и identity continuation разделены по независимым сценариям. Добавлены JSON-отчёты времени и воспроизводимое обновление весов; проверка типов Next вынесена в обязательный статический gate. Сохранены все assertions, responsive-матрица с обязательными снимками, проверки ошибок и правила выбора тестов. CI закреплён на Ubuntu 24.04 для проверки стабильности запуска системного Chrome. Веса пересчитаны по двум полным успешным прогонам; самые тяжёлые browser-shards распределены между разными runner jobs. Геометрия archetype/Vicious разделена по всем исходным viewport; необязательный quarantine стартует после обязательного gate. CI отдельно измеряет запуск каждого Chrome, чтобы различать старт браузера и время сценариев. Не прошедший hosted-проверку pipe-эксперимент откатан; добавлены числовые замеры ресурсов runner. Независимые сценарии back/forward cache разделены на три файла с сохранением проверок подписки, смены аккаунта и offline. Тестовые CI jobs явно используют системный Google Chrome; fixtures учитывают общий путь браузера, а лог запуска показывает выбранный executable. Проверка появления домашней ленты сохраняет реальную анимацию до чтения её параметров и ждёт завершения, чтобы не терять короткий эффект на занятом runner. Веса распределения обновлены по двум полным прогонам с единым Chrome; независимые проверки загрузки каталога и карточки разделены с сохранением всех viewport и assertions. Fixture временного сбоя подписки удерживает ответ восстановления до проверки pending-состояния, устраняя гонку чтения в тесте тир-листа БГ без изменения assertions и сроков ожидания. Проверка CSS главной страницы добавляет и удаляет временные элементы атомарно, чтобы не ломать гидратацию React; загрузка CSS поддержки и футера проверяется в существующем окне ожидания. CI использует готовые nginx и OpenSSL образа runner без обновления пакетов в каждой задаче; при отсутствии инструмента сохраняется установка и проверка запуска. Перед обязательными браузерными worker добавлен явный прогрев выбранного Chrome с закрытием процесса; его время учитывается в CI, ошибки запуска остаются блокирующими, а таймауты тестов не меняются.
