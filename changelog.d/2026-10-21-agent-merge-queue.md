Для сопровождающих: агенты больше не пушат в `main`, а открывают PR через
`npm run agent:integrate`; merge queue проверяет несколько PR вместе с
актуальным `main` и сам выкатывает результат. Записи журнала изменений теперь
отдельные файлы в `changelog.d/` и собираются в `CHANGELOG.md` при релизе
(`npm run changelog:assemble`), поэтому ветки не конфликтуют. Бюджеты размера
страниц Next.js — точный замер на каждую страницу плюс общий допуск 2 %;
замер больше не зависит от SHA сборки, а рост сверх допуска одобряется
отдельным файлом в изменении.
