Появился скрипт `scripts/ci-affected-tests.mjs`: по списку изменённых файлов он говорит, какие тесты из реестра затрагивает pull request (все, подмножество или ни одного), а раннер тестов принимает `--only-files`, чтобы запускать только выбранные файлы. В CI скрипт пока не подключён: pull request по-прежнему гоняет все тесты.
