Патчноуты: у каждого изменения теперь есть карта. Названия с пометками («Гнев К’Туна — Способность К’Туна», «Темный парадокс (2-й уровень)») находят свою карту, карты вне коллекции берутся из полного каталога, а карты Вольного, которых нет в архиве версий, показаны актуальной картинкой с сегодняшним текстом. Плашки считаются по версиям карты, а не по тексту статьи («Рыцарь-гибрид» — «Здоровье 3 → 4», «Текст» только если текст правда изменился). Там, где есть картинка, блоки «Было / Стало» убраны; у изменения совсем без картинки текст выводится один раз, изменённые слова подсвечены. Шапка патча стала короче (версия, дата, источники), строка «в статье только картинками» убрана. Названия карт в общих изменениях подсвечены, показывают карту при наведении и фокусе, а на телефоне открывают её по нажатию. Режимы обозначены баннером с артом своего режима и золотым значком из меню. Картинки карт из внешних каталогов показываются только через прокси изображений сайта; адрес с другого хоста отбрасывается, и вместо него выводится стандартный рендер карты.
