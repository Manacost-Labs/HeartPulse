# Чек-лист промо-кадра

Открой каждый файл. Ответь «да» на каждый пункт. «Нет» — пересними кадр.

## Смысл

- [ ] На кадре одна идея, её можно назвать одной фразой.
- [ ] Подпись правдива: каждое число и утверждение видно на кадре.
- [ ] Срез указан: формат, ранг или патч.
- [ ] Данные свежие: снято сегодня со стенда, не из старой папки.

## Читаемость

- [ ] Уменьши картинку до ширины 360 px: главное число и названия читаются.
- [ ] Подпись не больше двух строк, подзаголовок не больше двух строк.
- [ ] Кадр занимает основную площадь макета, а не узкую полосу.

## Чистота

- [ ] Нет «Поддержать проект», туров, тостов, баннеров, строки поиска.
- [ ] Нет полуобрезанных строк, столбцов, подписей.
- [ ] Нет «Повторить загрузку изображения», пустых картинок, скелетонов.
- [ ] Нет полос прокрутки и курсора.
- [ ] Нет английского текста там, где сайт пишет по-русски.

## Безопасность

- [ ] Нет имени, почты, аватара, ника или ID пользователя.
- [ ] Нет cookie, адресов `127.0.0.1` и служебных панелей.

## Файлы

- [ ] Есть `<id>-x-1200x675.png` и `.webp` (X, Telegram).
- [ ] Есть `<id>-vk-1080x1350.png` и `.webp` (VK, Instagram), если просили.
- [ ] Файлы @2x: 2400×1350 и 2160×2700.
