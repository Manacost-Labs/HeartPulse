# HearthPulse: промо-скриншоты

Правило: **один кадр — одна идея. Только настоящие данные. Читается на
телефоне в ленте.**

Скрипт сам поднимает локальный стенд, снимает кадры и всё останавливает.
Тебе нужно: рабочая копия, конфиг кадров, проверка результата глазами.

## Шаг 1. Подготовь рабочую копию

Скриншоты снимают код ветки, на которой стоишь. Для промо бери свежий
`origin/main`.

```bash
cd /srv/projects/tasks/hearthpulse-<task>-<YYYYMMDD>   # своя рабочая копия
npm ci
npm run build:next
```

1. Сборка Next нужна обязательно: стенд запускает `next start`.
2. Браузер — системный `/usr/bin/google-chrome`. Кэш `ms-playwright` не нужен.

## Шаг 2. Возьми конфиг

1. Скопируй образец `references/shots-top5.json` в свой scratchpad.
2. Поменяй кадры под задачу. Формат полей — `references/config.md`.
3. Селекторы блоков бери из таблицы в `references/config.md`.
   Нужного нет — найди класс блока: `git grep -n '<текст со страницы>' -- src`.

## Шаг 3. Сними

```bash
node .claude/skills/hearthpulse-promo-screenshots/scripts/shoot.mjs \
  --config <scratchpad>/shots.json \
  --out /srv/projects/tasks/hearthpulse-promo-shots-<YYYYMMDD>
```

1. Запускай из корня рабочей копии.
2. Папка вывода — вне git. В репозиторий картинки не коммить.
3. Один кадр: добавь `--only <id>`.
4. Строка `FAILED <id>` — кадр не снят. Исправь селектор или действие,
   повтори с `--only <id>`.
5. Строка `problems:` — запросы 4xx/5xx на странице. Открой кадр:
   если блок пустой или с ошибкой — кадр не годится.

Что делает скрипт:

- поднимает стенд: Express и Next.js из рабочей копии на свободных портах;
- создаёт одноразового подписчика во временной базе;
- открывает страницу с этим подписчиком и выполняет `actions`;
- ждёт шрифты, картинки и сеть;
- выключает анимации и `prefers-reduced-motion`;
- прячет шум: «Поддержать проект», туры, баннеры, липкие панели;
- снимает элемент `target` с отступом при DPR 2;
- кладёт кадр на фирменный фон с подписью и hearthpulse.net;
- пишет PNG и WebP в папку вывода, затем останавливает стенд.

## Шаг 4. Проверь каждый кадр глазами

Открой каждый PNG (Read). Пройди `references/checklist.md`.
Хоть один пункт «нет» — поправь конфиг и пересними этот кадр.

## Шаг 5. Убедись, что всё остановлено

```bash
STAND="$PWD/node_modules/(tsx/dist/cli.mjs server/index.ts|next/dist/bin/next start)"
pgrep -af "$STAND" || echo 'стенд остановлен'
```

Команда ищет только процессы твоей рабочей копии. Остался процесс —
останови его: `kill <pid>`. Чужие процессы не трогай.
Если запускал `stand.mjs` вручную — Ctrl+C в его терминале.

## Данные и доступ: только так

<!-- markdownlint-disable MD013 -->

| Можно | Нельзя |
| --- | --- |
| Локальный стенд `scripts/stand.mjs`: Express рабочей копии читает публичные данные (`api.kolodahearthstone.com`, HSGuru), как прод | Cookie, токены и сессии с прода |
| Одноразовый подписчик `promo@example.test` во временной базе (ручная выдача доступа, как делает администратор) | Чужие аккаунты, свой аккаунт на проде, копия боевой базы |
| Подпись и цифры из того, что видно на кадре | Придуманные цифры, правка данных в DOM, моки статистики |

<!-- markdownlint-enable MD013 -->

1. Временная база и файлы стенда удаляются при остановке.
2. Стенд слушает только `127.0.0.1`. Фоновые задачи и Redis выключены.
3. Нужно посмотреть страницу руками — `node <skill>/scripts/stand.mjs`:
   он печатает адрес и cookie. Остановка — Ctrl+C.
4. Кадр гостя: в кадре `"access": "guest"`.

## Правила хорошего промо-кадра

1. **Одна идея.** Один блок: карта меты, или матрица, или муллиган.
   Не страница целиком.
2. **Настоящие данные.** Актуальный срез. Подпись говорит только то,
   что видно на кадре.
3. **Читается мелко.** Кадр смотрят на телефоне шириной ~360 px:
   обрезай до 8–15 строк таблицы, для портретного формата снимай узкий
   viewport (480) или выше обрезку.
4. **Без личных данных.** Нет имён, почты, аватаров, ников, ID профилей.
5. **Текст — 1–2 строки.** `caption` до ~45 знаков, `subcaption` — срез и период.
6. **Без мусора.** Нет кнопок «Поддержать проект», туров, тостов, полос
   прокрутки, полуобрезанных строк (`snap`), ошибок загрузки картинок.
7. **Русский текст.** Английское имя архетипа допустимо, только если сайт
   сам его так показывает.
