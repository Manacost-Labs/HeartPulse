# HearthPulse: как выглядит страница

`design.md` в корне — источник истины по цветам, шрифтам, ассетам и
запретам. Этот скилл — практическая выжимка: из чего собирать страницу,
чтобы она выглядела как остальные обновлённые разделы, и какие ошибки
владелец уже отклонял.

Эталоны (открывай и сравнивай со своим результатом):

- шапка, KPI, история, муллиган, сборки — страница архетипа,
  например `https://hearthpulse.net/standard/archetypes/standard/<slug>/`;
- таблица и тиры — `https://hearthpulse.net/standard/meta/`;
- матрица и обзор — `https://hearthpulse.net/standard/matchups/`.

## Шаг 1. Материал и токены

- Цвета, шрифты, отступы, радиусы — только токены: `src/styles/tokens.css`
  (`--arena-parchment*`, `--arena-ink`, `--arena-muted-ink`, `--arena-red*`,
  `--arena-gold*`, `--arena-wood-dark`, `--arena-wood-divider`), шрифты
  `--font-display` (HSDisplay, заголовки) и `--font-body` (Inter, всё
  остальное). Правила — в скилле `css-tokens`.
- Холст — пергамент через `var(--arena-parchment-texture)`, крупные блоки
  в деревянной рамке (`/wallpaper/main-page-rail-border.png`), между
  разделами тонкий деревянный разделитель `--arena-wood-divider`.
- Белый, молочный и голубой фон страницы запрещены. Золото — только мелкие
  акценты, не заливка панелей.
- Цвета данных: хорошо `#2f7a3e`, плохо `#a33a3a` (design.md). Только для
  метрик, не для украшений.
- Цвет редкости карты — токены `--card-rarity-glow-*`; арт карт, портреты,
  кристаллы маны CSS-фильтрами не перекрашивать.

## Шаг 2. Анатомия страницы

Сверху вниз, ничего не дублируя:

1. **Кинематографическая шапка.** Одно полотно: арт класса на всю ширину
   (`public/archetype-art/classes/<class>-{960,1920}.webp`, выбор в
   `src/features/archetypeDetailModel.ts`), градиент слева под заголовком,
   справа арт виден. Иконка класса + заголовок `--font-display`. Пример —
   `.archetype-dossier` в `src/features/ConstructedArchetypes.css`.
   Картинка шапки — `fetchpriority="high"` и правильный `sizes`.
2. **KPI-полоса** внутри шапки: полупрозрачная с размытием
   (`background: rgba(30,4,9,.5)` + `backdrop-filter: blur(10px)`),
   значения с трендом и спарклайном. Компонент —
   `src/features/ArchetypeDossierKpis.tsx` (KPI Group из VaryloUI).
3. **Разделы.** Заголовок раздела всегда из трёх частей: eyebrow (иконка +
   короткая метка капсом), заголовок `--font-display`, одна строка
   описания. Пример — `archetype-analysis-panel__eyebrow` в
   `src/features/ArchetypeDetailSections.tsx`.
4. **Содержимое раздела** — одна рамка, внутри одна мысль: таблица, или
   график, или галерея. Без вложенных «карточек в карточках».

## Шаг 3. Правила показа данных

- **Винрейт всегда относительно 50%.** Полоса от центральной линии 50%,
  рядом 95% интервал Уилсона: `wilsonInterval()` из
  `src/features/archetypeInsightsModel.ts` (не пиши свою формулу).
  Примеры: `src/features/StandardMetaWinrateCells.tsx`,
  `src/features/archetypeComparisonModel.ts`.
- **Цвет — расходящаяся шкала вокруг 50%**: красный ниже, зелёный выше,
  яркость от отклонения, гашение шириной интервала. Готовая функция —
  `rankHeatCell()` в `src/features/archetypeRankHeatModel.ts`; цифра в
  клетке держит контраст ≥ 4.5:1.
- **Малая выборка — приглушить, а не подписать.** Непрозрачность 0.72–0.78
  и значок ⓘ с подсказкой у размера выборки
  (`ConstructedArchetypeCardStatsCells.tsx`). Не выводи под элементом текст
  «мало данных».
- **Честные ряды.** «Нет данных» ≠ 0: линия рвётся. При смене периода
  (патч → «Тёмная империя») линия рвётся и граница подписана. Накопительный
  счётчик внутри периода показывай как прирост за срез, а не «пилой».
  Изменение считай только к реальному прошлому значению.
- **Только реальные данные и ассеты.** Нет данных — не рисуй компонент и
  напиши в отчёте, чего не хватает. Сгенерированные картинки запрещены.
- **Названия по-русски**, английское — мелкой подписью обычным регистром
  под русским. Совпавшие переводы разводит сервер скобками (см. память о
  коллизиях архетипов), не правь это на странице.
- Цифры в колонках — `font-variant-numeric: tabular-nums`.

### VaryloUI и Valyro (библиотеки владельца)

- Лежат вендорно: `src/vendor/varylo-ui/` и `src/vendor/valyro-ui/`.
  Перед добавлением прочитай их `README.md`.
- Источники на сервере: VaryloUI — `/home/debian/varylo-ui-release/r/<item>.json`,
  Valyro — `/home/debian/valyro-ui-release/r/<item>.json`,
  Valyro Pro — `/home/debian/valyro-pro-registry/<item>.json`. Пакета
  `valyro-ui-pro` в npm нет: копируй файлы item'а из JSON реестра в тот же
  путь под `src/vendor/<kit>/`, только нужные item'ы, без чужих тем.
- Чужие файлы не правь руками; каждое локальное изменение — с комментарием
  `HearthPulse` и строкой в README кита.
- Тема: не тащи `styles/themes/*`. Подключай базу
  `src/vendor/varylo-ui/styles/index.css` один раз и сопоставляй `--ui-*`
  токены с нашими в своей области: `src/shared/ui/varyloParchment.css`,
  `src/features/archetypeVaryloTheme.css`, `src/features/StandardMetaVarylo.css`.
  Вторую копию базовых стилей (`.ui-panel`, `.ui-floating`) в другой чанк не
  клади — она перебьёт правила страниц.
- Уже есть: DataTable, KPI Group, ConfidenceBand, Heatmap, MetricComparison,
  RadarChart, ScatterChart, Treemap, MatchupMatrix, MetaTable, Sparkline,
  TrendValue, Leaderboard, TierList, PatchNotes, SankeyChart, Combobox.
  Сначала ищи в `src/vendor`, потом в реестре.

## Шаг 5. Телефон (412 px)

- Нет горизонтальной прокрутки страницы. Широкая таблица — прокрутка внутри
  своего контейнера с закреплённой первой колонкой.
- Матрицы и широкие таблицы → список строк-карточек.
- Превью и детали → bottom sheet, не всплывающее окно.
- Цели нажатия ≥ 42 px.

## Анти-паттерны (владелец уже отклонял)

- Шапка из двух склеенных кусков (плашка + отдельный квадрат арта) вместо
  одного полотна.
- Большая фиолетовая кнопка «→» в каждой строке. Ссылка — вся строка.
- Внутренняя прокрутка в колонках с обрезанной последней строкой; неравные
  колонки «30 строк / 3 строки».
- Крошечные блёклые подсказки, перекрывающие ячейку.
- Обрезанные подписи в treemap; серые плитки архетипов вместо оттенков
  цвета класса.
- «Голая» страница без ассетов (только текст) — и обратное: мусор, одни и
  те же счётчики трижды, несколько навигаций для одного (плитки + полоса +
  оглавление + таймлайн).
- Английские названия без перевода, капслок английских подписей.
- Ложные нули и «пила» на графиках; кнопки периодов, где данных нет.
- Чёрные поля вокруг рендера внутри рамки.
- Строка «Мета: архетипы · текущие строкиCSV» — служебные подписи
  компонента наружу не выводить.

## Проверь перед READY

- [ ] Цвета и тайминги только из токенов; `npm run lint:architecture` зелёный.
- [ ] Шапка — одно полотно; у каждого раздела eyebrow + заголовок + строка.
- [ ] Винрейт от 50% с интервалом; малые выборки приглушены, не подписаны.
- [ ] Нет ложных нулей, разрывы на смене периода, данные только реальные.
- [ ] Русские названия, английские — мелко ниже.
- [ ] Ничего не повторяется дважды (счётчики, навигация, подписи).
- [ ] 1440 и 412: без горизонтального скролла, подсказки читаются.
- [ ] Скриншоты сравнены с эталонной страницей выше.
