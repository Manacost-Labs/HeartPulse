# HearthPulse: дизайн страницы

## Правило №1. Вкус владельца

Страница — **аккуратный профессиональный инструмент без мусора и лишних
деталей.**

Запрещено:

1. Одно и то же число дважды на экране.
2. Две навигации для одного и того же (вкладки + плитки + оглавление).
3. Декоративные подписи и метки: «мало данных», «текущие строки»,
   «Сборки HSGuru», служебные заголовки компонентов.
4. Английский текст, если есть русский.
5. Большие цветные кнопки в каждой строке.
6. Пустое место и пустые блоки.
7. Лишние рамки, заливки и тени.
8. Больше одного акцента на блок.

**Сомневаешься — убери.**

## Правила данных

1. Винрейт показывай относительно 50% с интервалом: `WinrateCell`.
2. Малую выборку приглушай: `opacity: .75` и значок ⓘ. Текст не пиши.
3. В топах малые выборки исключай.
4. «Нет данных» — это не 0. Линия рвётся.
5. Смена периода рвёт линию. Через неё не сравнивай.
6. Изменение = `winrate − trend.previous.winrate` из `/api/standard-meta/trends`,
   как в таблице меты. Другие формулы не придумывай.
7. Русское имя — `archetypeLabel`. Английское — `archetype`, мелко, ниже.
8. Только реальные данные и картинки. Нет данных — нет блока.
9. Блок на существующей странице берёт данные, которые страница уже
   загрузила. Свой `fetch`, свой период и свои фильтры не добавляй.

## Правила вида

1. Цвета, шрифты, тайминги — токены из `src/styles/tokens.css`.
2. Литералы из шаблонов копируй как есть. Не придумывай новые цвета.
3. Фон страницы — пергамент. Белый и голубой фон страницы запрещены.
4. Рамка `main-page-rail-border.png` — только у раздела верхнего уровня.
5. Внутри раздела группы разделяй линией `--arena-paper-line`.
6. Иконки — `lucide-react`, всегда `aria-hidden="true"`.
7. Иконка класса — `classIconUrl(classKey)` или `standardMetaClassIcon`.
8. Числа в колонках — `font-variant-numeric: tabular-nums`.
9. Телефон 412 px: без горизонтальной прокрутки страницы.
10. Цели нажатия на телефоне — не меньше 42 px.

## Сделано, если

Запусти в своей рабочей копии:

```bash
npm run lint
npm run lint:architecture
npm run build-storybook && npm run test:storybook
npm run budget:next
npm run qa:ci
```

Все команды зелёные, и:

- [ ] Ни одного пункта из «Правила №1» на экране.
- [ ] Решение взято из таблицы «Фиксированные решения».
- [ ] Код скопирован из шаблона, изменены только данные и имена.
- [ ] Скриншоты 1440 и 412 сделаны и сравнены с эталоном:
  `/standard/archetypes/standard/<slug>/`, `/standard/meta/`,
  `/standard/matchups/`.
- [ ] На 412 нет горизонтальной прокрутки.
