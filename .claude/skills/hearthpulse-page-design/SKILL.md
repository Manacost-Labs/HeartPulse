# HearthPulse: как выглядит страница

Цель: страница выглядит как уже принятые владельцем разделы, а не как
«дашборд из карточек». Источник истины по токенам и запретам —
`design.md` в корне; здесь — практические решения и шаблоны.

Справочники рядом с этим файлом:

- `references/snippets.md` — шаблоны кода для копирования (шапка, KPI,
  раздел, винрейт с интервалом, малая выборка, график, сравнение, доли,
  тема, телефон);
- `references/components-and-data.md` — пропсы готовых компонентов,
  строка-ссылка, иконки, `classKey`, откуда брать данные, фикстуры;
- `references/vendoring.md` — как добавить компонент VaryloUI/Valyro;
- `references/before-after.md` — что владелец отклонил и что принял.

Эталоны (сравнивай свой скриншот с ними):

- страница архетипа: `/standard/archetypes/standard/<slug>/`;
- мета: `/standard/meta/` (Таблица, Тиры, Доли, Карта);
- матчапы: `/standard/matchups/` (Матрица, Обзор архетипа).

## Шаг 2. Материал

- Только токены `src/styles/tokens.css` (правила — скилл `css-tokens`):
  `--arena-parchment*`, `--arena-ink`, `--arena-muted-ink`, `--arena-red*`,
  `--arena-gold*`, `--arena-wood-dark`, `--arena-paper-line`,
  `--arena-wood-divider`; шрифты `--font-display` (заголовки) и
  `--font-body` (всё остальное).
- Холст — `var(--arena-parchment-texture)`. Крупный блок — рамка
  `border-image: url('/wallpaper/main-page-rail-border.png') 18 stretch`.
- Белый, молочный, голубой фон **страницы** — нельзя (светлый кремовый
  фон подсказок и плашек внутри раздела — можно). Золото — только мелкие
  акценты. Хорошо/плохо в данных — `#2f7a3e` / `#a33a3a` (или `TrendValue`).
- Новые значения — через токены. Литералы в шаблонах `references/` —
  принятая палитра эталона: копируй как есть, не «улучшай».
- Арт карт, портреты, кристаллы маны не перекрашивать фильтрами.
- Иконки — `lucide-react`, иконки классов — `classIconUrl(classKey)`.

## Шаг 3. Анатомия (сверху вниз, без повторов)

1. Шапка — одно полотно: арт класса на всю ширину, градиент под текстом,
   иконка + h1, KPI-полоса с размытием (snippets §1–2).
2. Одна навигация по странице (вкладки или переключатель вида,
   `SegmentedControl`), не несколько параллельных. Блок зависит от
   фильтров вида (ранг, период) — ставь внутрь вида; не зависит — под
   шапкой над переключателем.
3. Разделы: рамка → eyebrow + h2 + одна строка описания → одно содержимое
   (snippets §3).
4. В пределах одного экрана каждое число показано один раз. Счётчик в
   шапке не повторяется в разделе; `__count` — только если этого числа
   больше нигде нет. Блок-выжимка (топ роста) может повторить число из
   таблицы ниже, но показывает в первую очередь своё (изменение), а не всю
   ячейку.
5. Рамка `main-page-rail-border.png` — только у разделов верхнего уровня;
   группы внутри раздела разделяй тонкой линией `--arena-paper-line`.
6. Несколько групп в одном разделе (рост / падение / новые) — равные по
   высоте: одинаковый лимит строк (например, 5) и «Показать все» для
   остатка, или одна колонка с подзаголовками. Пустая группа — короткая
   строка «Нет изменений за неделю», не исчезающая колонка.

## Шаг 4. Данные — честно

- Винрейт всегда относительно 50% с интервалом Уилсона: для строк —
  `standardMetaWinrateEstimate` + `WinrateCell` (snippets §4). Функций
  Уилсона две, со шкалами процентов и долей —
  `references/components-and-data.md`.
- Изменение к прошлому периоду — из готовых трендов
  (`/api/standard-meta/trends`); значок изменения — `TrendValue` или
  `WinrateCell`. Через смену периода не сравнивай.
- Цвет — расходящаяся шкала вокруг 50% (`rankHeatCell` из
  `src/features/archetypeRankHeatModel.ts`), цифра контрастна ≥ 4.5:1.
- Малая выборка — приглушить (0.72–0.78) и ⓘ у размера выборки; текст
  «мало данных» под элементом не писать (snippets §5).
- «Нет данных» ≠ 0; смена периода рвёт линию; накопительное — как прирост;
  изменение только к реальному прошлому значению.
- Только реальные данные и ассеты. Нужных данных нет в API — остановись и
  спроси ведущую сессию; нет данных совсем — компонента нет, в отчёте
  написано, чего не хватает.
- В «топах» (рост, падение, лучшие) строки с малой выборкой исключай; в
  таблицах — приглушай.
- Русские названия (`archetypeLabel`), английское (`archetype`) — мелко
  ниже обычным регистром.
- Числа в колонках — `font-variant-numeric: tabular-nums`.

## Шаг 5. Компоненты библиотек

- VaryloUI и Valyro лежат в `src/vendor/varylo-ui/` и `src/vendor/valyro-ui/`;
  добавление — строго по `references/vendoring.md`.
- База стилей одна: `src/vendor/varylo-ui/styles/index.css`. Тема —
  обёртка-класс из `archetypeVaryloTheme.css` / `varyloParchment.css` /
  `StandardMetaVarylo.css` (snippets §9).
- Служебные подписи компонента (заголовок, caption DataTable) наружу не
  выводить; подсказки (`--ui-elevated`) непрозрачные.

## Шаг 6. Телефон 412 px

- Нет горизонтальной прокрутки страницы; широкая таблица скроллится в своём
  контейнере с закреплённой первой колонкой.
- Матрица → список; детали → bottom sheet; цели нажатия ≥ 42 px
  (snippets §10).

## Анти-паттерны (подробно в `references/before-after.md`)

- Шапка из двух склеенных кусков.
- Кнопка «→» в каждой строке вместо ссылки на всю строку.
- Внутренняя прокрутка колонок, неравные колонки.
- Мелкие блёклые подсказки поверх ячейки.
- Серые обрезанные плитки treemap; treemap без списка.
- «Голая» страница без ассетов — и обратное: одни и те же числа и
  навигации по 3–4 раза.
- Английские имена капсом.
- Ложные нули, «пила», кнопки пустых периодов.
- Чёрные поля вокруг рендера.
