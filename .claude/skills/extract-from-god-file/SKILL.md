# Вынесение из god-файла

Текущие цели и их размер: `server/index.ts` ~9900 строк,
`DeferredRoutes.tsx` ~6400, `Battlegrounds.tsx` ~4370, `App.tsx` ~1966.
Бюджеты — в `scripts/check-module-size-budgets.mjs`.

## Шаг 1. Выбери один кусок

Один заход = одна страница, один домен или одна связная группа хелперов.
Не выноси два куска сразу. Если кусок тянет за собой половину файла —
значит границу выбрал неверно, ищи другую.

## Шаг 2. Зафиксируй эквивалентность до переноса

Найди тесты, покрывающие кусок, и запусти их **до** правки — нужен зелёный
базовый прогон, иначе потом не отличишь свою поломку от чужой:

```bash
npm run test:<домен>
```

Если тестов нет — сначала напиши characterization-тест на текущее поведение
и закоммить его отдельно. Это единственный случай, когда тест пишется
до рефакторинга.

## Шаг 3. Перенеси без единой правки

Скопируй код в новое место **дословно**. Меняй только импорты и экспорт.
Не переименовывай, не «причёсывай», не исправляй замеченные баги.

Коммит перенос отдельно: `refactor(<домен>): move X to Y`.
Проверь, что это действительно перенос:

```bash
git diff -M --stat
```

## Шаг 4. Только потом меняй

Разделение на `ui`/`model`/`api` (фронт) или `routes`/`service`/`repository`
(бэк) — **следующий** коммит: `refactor(<домен>): split Y into modules`.
Исправление найденного бага — **третий** коммит с префиксом `fix`.

## Шаг 5. Опусти бюджет

Сократил файл — опусти его порог в `scripts/check-module-size-budgets.mjs`
до нового фактического значения тем же коммитом. Порог только вниз.

## Шаг 6. Докажи, что ничего не изменилось

```bash
npm run lint && npm run lint:architecture
npm run test:<домен>
npm run qa:screens     # если трогал фронтенд
```

Contract- и E2E-тесты должны пройти **без правок в самих тестах**.
Если тест пришлось поменять — ты изменил поведение, а не структуру.

## Чего не делать

- Не выносить и не чинить в одном коммите.
- Не менять сигнатуры «заодно, раз уж всё равно трогаю».
- Не поднимать бюджеты, чтобы промежуточное состояние прошло проверку.
- Не оставлять реэкспорт-заглушку навсегда: она допустима внутри одной фазы
  как мост, но удаляется до конца фазы.
