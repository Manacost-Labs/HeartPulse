# Границы слоёв

## Фронтенд: направление зависимостей

```
app  →  features  →  entities  →  shared
```

Слой импортирует только слои **ниже** себя. Никогда наоборот.

| Слой | Что лежит | Что можно импортировать |
|---|---|---|
| `src/app/` | шелл, провайдеры, роутер, error boundaries | всё ниже |
| `src/features/<домен>/<фича>/` | доменные фичи-слайсы | `entities`, `shared`, другие слайсы через их `index.ts` |
| `src/entities/` | доменные модели без UI страниц | `shared` |
| `src/shared/` | ui-примитивы, lib, api-клиент, styles | ничего из вышестоящих |

Домены фичей: `arena`, `battlegrounds`, `constructed`, `editorial`, `admin`.

## Правило единственного входа

Между слайсами — импорт **только через `index.ts`**:

```ts
// можно
import { TierListPage } from '@/features/arena/tierlist';

// нельзя: глубокий импорт в чужой слайс
import { Table } from '@/features/arena/tierlist/ui/Table';
```

Внутри своего слайса глубокие импорты разрешены.

## Бэкенд

```
server/app/  →  server/modules/<домен>/  →  server/platform/
```

- `routes.ts` — только HTTP: разбор, валидация, коды ответов. **Не ходит в БД.**
- `service.ts` — бизнес-логика. **Не импортирует `express`.**
- `repository.ts` — доступ к данным. **Без бизнес-логики.**
- `public.ts` — единственный публичный вход в модуль.

Эталон готового модуля: `server/modules/publicApi/`.

## Починка типовых падений

**`import/no-cycle`.** Цикл почти всегда значит, что общий кусок лежит не на
том слое. Не разрывай цикл динамическим `import()` — вынеси общее вниз:
в `entities` (фронт) или `platform` (бэк). Найти цикл:

```bash
npx eslint --rule '{"import/no-cycle":"error"}' src server
```

**`no-restricted-imports`.** Ты импортировал вверх по слоям или в обход
`index.ts`. Либо экспортируй нужное из `index.ts` слайса-источника, либо —
если тянет вверх — перенеси общее вниз.

## Чего не делать

- Не добавлять новый домен верхнего уровня, не спросив.
- Не обходить правило через относительные пути `../../..`.
- Не глушить правило `eslint-disable` ради «временного» импорта.
- Не документировать границу вместо того, чтобы включить её в линтер:
  граница, которая не падает в CI, не существует.
